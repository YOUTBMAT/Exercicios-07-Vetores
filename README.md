## 📌 Sobre o Projeto

Este repositório reúne a resolução de uma lista de exercícios focada em **Estruturas de Dados Unidimensionais (Vetores)** em Python. 

O objetivo principal é dominar a manipulação de coleções sequenciais de dados, compreendendo como armazenar, acessar e transformar conjuntos de variáveis sob um mesmo nome, utilizando índices lineares.

### 🧠 Conceitos Explorados:
- **Indexação Linear:** Acesso direto a elementos através de índices baseados em zero (`vetor[i]`).
- **Iteração Sequencial:** Uso de estruturas de repetição (`for` e `while`) para percorrer e manipular listas.
- **Operações com Vetores:** Algoritmos para busca do maior/menor valor, soma de elementos, médias e inversão de ordem.
- **Filtragem e Condicionais:** Varredura de estruturas para extração de subconjuntos de dados (como separar números pares de ímpares).

## 📐 Importância da Estrutura

Dominar o uso de vetores é o primeiro passo para compreender como a memória do computador organiza dados em lote. Esta estrutura linear serve como base fundamental para conceitos mais complexos da Ciência da Computação, incluindo matrizes, pilhas, filas e análise estatística de dados.
